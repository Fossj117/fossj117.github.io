Today started some work on measurement. Measurement feels like something more conceptual -- I get the concept, the question is more how to work it into my practice when actually drawing. It also gets into some deeper questions about much I value precision and accuracy when drawing; I guess surely it's good to have the option to be precise, but I find it challenging sometimes to balance precision and expressiveness.
